What a good prompt spells out:

- **Scope and red lines** (what not to do, which actions need your go-ahead).
- **Where the output goes and in what format** (which file, which language, one file or several).
- **How it will be accepted** (the check passes, screenshots reviewed, not-verified items listed).
- For long tasks, **how to resume after an interruption**.

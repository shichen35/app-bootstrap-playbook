# Scope

This repo collects skills for one process: taking a native app from idea to store release on Android, iOS and macOS.

## What gets accepted

An idea or change is accepted only if it meets both criteria:

1. **It solves a problem that actually happened**: in a real project, while following this repo's skills, something went wrong, and you can say what should have happened instead. "It would be nice if…" does not count.
2. **It fits how this repo works**: it does not revisit an idea already rejected in [`.out-of-scope/`](.out-of-scope/), and it is not a setting for one person's workflow. Personal preferences belong in your own `CLAUDE.md` / `AGENTS.md`, or in a fork.

## New skills

If existing skills can be combined to do it, do not add a new one. Put a new stage practice into an existing skill or `process/` first, and consider promoting it to its own skill only after it has worked in a real project.
